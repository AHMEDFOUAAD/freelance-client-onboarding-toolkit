# Project Scope & Discovery Intake Questionnaire

**Send this questionnaire to clients after initial contact to gather structured project requirements before preparing a proposal or Statement of Work (SOW).**

---

### Client Information
- **Company Name:**
- **Primary Contact Name & Title:**
- **Email / Phone:**
- **Website / App URL:**

---

### Section 1: Business Context & Objectives
1. **What primary business problem does this project solve?**
   *(e.g., Manual data processing between tools, slow page loads hurting conversions, lack of API integration)*

2. **How does your team currently handle this process?**
   *(Describe the current manual workflow, tools used, and where bottlenecks occur)*

3. **What is the measurable definition of project success?**
   *(e.g., Process completed in under 5 minutes, 99.9% uptime, 50 hours of developer time saved per month)*

---

### Section 2: Technical Scope & System Environment
4. **What systems, platforms, or APIs will this project interact with?**
   *(List existing languages, frameworks, cloud services, and third-party tools)*

5. **Are staging/development environments and API credentials currently available?**
   *(Yes / In Progress / Need setup)*

6. **What specific deliverables do you expect at project handoff?**
   *(e.g., Documented source code in Git, deployed container on AWS, technical handover documentation, admin dashboard)*

---

### Section 3: Timeline, Stakeholders & Budget
7. **What is your target launch or completion date, and what drives this deadline?**
   *(e.g., Q1 product release, marketing campaign launch, board meeting)*

8. **Who has final sign-off authority for reviewing and approving deliverables?**
   *(Name and role)*

9. **What approved budget range has been allocated for this engagement?**
   - [ ] Tier 1: $2,500 – $5,000 (Focused integration or MVP feature)
   - [ ] Tier 2: $5,000 – $10,000 (Complete end-to-end subsystem or automation)
   - [ ] Tier 3: $10,000 – $25,000+ (Full platform, architecture overhaul, or ongoing monthly retainer)

10. **Are there any hard constraints, compliance rules, or non-negotiables we should know about?**
    *(e.g., GDPR, HIPAA, strict cloud provider requirements)*
